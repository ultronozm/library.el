#+title: library.el: Helper functions for managing downloaded papers
#+author: Paul Nelson

* Overview
This package provides commands for managing downloaded papers and their associated BibTeX.  It is simpler and less featureful than the many existing packages addressing this general need, such as [[https://github.com/cpitclaudel/biblio.el][biblio.el]] and [[https://github.com/emacsmirror/zotero][emacs-zotero]], but I wasn't able to get those to do exactly what I wanted.

The most common ways that I use this package are as follows:

** Opening the most recently downloaded paper: =library-find-newest-downloaded-pdf=
After I've downloaded a paper, the first thing I want to do is open it in Emacs (using [[https://github.com/vedang/pdf-tools][pdf-tools]]).  I do this by running the command
=library-find-newest-downloaded-pdf=, which, unsurprisingly, searches through my downloads folder and opens the newest PDF file that it finds.

** Processing papers downloaded from the arXiv: =library-process-arxiv=
If the paper came from the arXiv, then, after opening it in Emacs, I run the command =library-process-arxiv=, which does the following:
- Download bibliographic data for the paper using the arXiv API.
- Move the file to a designated PDF storage folder (for me, in Dropbox) and rename it to something intelligible, containing the publication year, authors and title, so that, later, I can easily find the paper.
- Add a BibTeX entry to my "refs.bib", so that, later, I can easily cite the paper.
- Add a journal entry to my "log.org" with a link to my downloaded copy of the paper, so that I can keep track of when I looked at which papers.  I also often use this as a place to store paper-specific notes-to-self (typically in an [[https://orgmode.org/worg/org-contrib/babel/languages/ob-doc-LaTeX.html][org-mode LaTeX source block]]).  

  Notes:

  1. For papers using old arXiv identifiers, this command assumes that they came from "math".  For non-math papers, see below.

  2. I often compress these two steps into one using =library-download-arxiv=, see below.

** Processing papers downloaded from other sources: =library-process-clipboard=
For a paper coming from somewhere other than the arXiv (or an old non-math arXiv paper), I find a BibTeX entry for that paper (typically using [[https://mathscinet.ams.org/mathscinet/publications-search][MathSciNet]]) and copy it to the clipboard.  Then, after opening the paper in Emacs, I run the command =library-process-clipboard=.  This carries out the same steps as above, but using the BibTeX stored in the clipboard rather than that obtained via the arXiv API.

** Filing drafts and other local documents: =library-process-manual=
For a thesis draft, informal notes, or another PDF without a downloadable
citation, run =library-process-manual= while viewing the PDF or on its file
in Dired.  Elsewhere it prompts for a file; a prefix argument always prompts.

The command displays the PDF and a BibTeX template in separate windows.
Edit the suggested citation key and fill in the author and title.  The
template defaults to =@unpublished=; change the entry type and add fields
as needed.  Use =note=
for descriptions such as "Draft habilitation thesis, Université de Lille".
Leave the year blank if it is unknown: the filename will use =undated=,
without inventing a year in your bibliography.

Type =C-c C-c= to move and rename the PDF, register the citation, and create
the usual journal entry.  The PDF opens at its new location, and the
minibuffer reports the citation key.  Type =C-c C-k= to discard the template
and return to your previous windows without filing anything.  Filing errors
leave the template available for correction.  Existing citation keys and
destination files are refused, so a draft cannot silently replace an older
copy.  Keep personal reading or review notes in the journal entry.

* Configuration
This package requires [[https://github.com/ultronozm/czm-tex-util.el][czm-tex-util.el]], so install that first.

Download this repository, install using =M-x package-install-file= (or package-vc-install, straight, elpaca, ...), and add something like the following to your [[https://www.emacswiki.org/emacs/InitFile][init file]]:
#+begin_src elisp
(use-package library
  :custom
  (library-pdf-directory "~/Dropbox/math documents/unsorted/")
  (library-bibtex-file "~/doit/refs.bib")
  (library-download-directory "~/Downloads/")
  (library-arxiv-source-directory "~/Dropbox/math documents/arxiv-sources/")
  (library-download-arxiv-include-source t)
  (library-local-pdf-link-name "Dropbox link")
  (library-org-capture-template-key "j"))

(add-to-list 'org-capture-templates
             '("j" "Journal" entry (file+datetree "~/doit/log.org")
               "* %?\nEntered on %U\n"))
#+end_src

Modify suitably, replacing the paths above with paths to your own PDF storage directory, BibTeX file, download directory, and log file.

You can customize the file-naming scheme by modifying the user option =library-generate-filename-function=, e.g., by adding under the custom heading =:custom= above the entry =library-generate-filename-function my-filename-function= and writing your own function =(defun my-filename-function (entry year author title) ...)=, perhaps by copying the source code of the built-in default =library--generate-filename= and modifying it to your liking.

* Usage
The three commands that I use most often were described already in [[Overview]].  The following supplementary commands are occasionally useful:
- =library-download-preprint= :: Download and process a preprint from arXiv or Hexagon.  Accepts arXiv identifiers/URLs and Hexagon URLs such as =https://hexagonmath.org/2610.00200v1= or =hexagon:2610.00200v1=.  Bare identifiers still mean arXiv.  The existing =library-download-arxiv= command accepts the same inputs.  Hexagon downloads use its BibTeX citation, adding its listed contributors as authors when needed for naming, and record a Hexagon journal link.  The existing =library-download-arxiv-include-source= and =library-arxiv-source-directory= settings also control Hexagon ZIP sources.
- =library-download-arxiv= :: This command prompts for an arXiv identifier and downloads and processes the corresponding PDF, visiting it when the command is called interactively.  When =library-download-arxiv-include-source= is non-nil, it also downloads and extracts the arXiv source archive into a subdirectory of =library-arxiv-source-directory=, named after the processed PDF.  This option is enabled by default and applies to calls from Lisp as well as interactive use.  An explicit second Lisp argument overrides it.  Existing source directories are preserved; remove or move one before downloading a replacement.  Lisp calls return a plist of the form =(:pdf PDF-PATH :source SOURCE-DIRECTORY)=; the source value is nil when no source was downloaded.
- =library-download-arxiv-source= :: This command prompts for an arXiv identifier and downloads and extracts just the source archive into a subdirectory of =library-arxiv-source-directory=.  When possible, the subdirectory uses the same year/authors/title naming scheme as PDFs.  The command accepts bare identifiers and arXiv abstract/PDF/source URLs.
- =library-process-arxiv-manual-id= :: The command =library-process-arxiv= determines the arXiv identifier for the current file by looking at the file name.  This command behaves similarly, but instead prompts for the arXiv identifier from the minibuffer.  Useful for arXiv downloads that you've already renamed.
- =library-process-arxiv-dired= :: This command processes the marked PDF files in [[https://www.gnu.org/software/emacs/manual/html_node/emacs/Dired.html][Dired]], assuming that each file has been downloaded from the arXiv and has not been renamed.  This is useful for when you have multiple unprocessed downloaded arXiv papers.
- =library-clipboard-to-refs= :: This command adds the BibTeX stored in the clipboard to the references file.  Useful for when you want to a cite a paper, but don't care to download it.
- =library-move-pdf= :: Move a PDF to the storage folder with a manually supplied filename, without registering a citation.  Use =library-process-manual= to make it citable as well.

* Importing a PDF from Lisp
Use =library-import-pdf= with a local PDF path and a BibTeX entry string:

#+begin_src emacs-lisp
(library-import-pdf "/tmp/paper.pdf" bibtex)
;; Explicitly replace an existing PDF, optionally recording an arXiv link:
(library-import-pdf "/tmp/published.pdf" bibtex t "0911.2274")
#+end_src

The function returns the filed PDF path, deposits the bibliography, and
creates a journal entry according to =library-org-capture-template-key=.
It reuses existing metadata for an exact citation-key match.  It refuses
an existing destination by default, before changing files or bibliography.
Replacement does not make a backup.  Downloading files, updating existing
metadata, and preserving older versions remain the caller's responsibility.
Edited volumes use their editors in filenames and an =EDITORS= journal property.
Entries require a nonblank title and author or editor; the year is optional.
Missing or blank years use =undated= in filenames and journal properties,
while the BibTeX is stored as supplied.  Journal entries also record the
citation key in a =CITEKEY= property.

A failed move leaves the bibliography unchanged.  Once the PDF has been
filed, a bibliography save or journal capture failure produces a warning
and still returns its path.  After a save failure, the new citation remains
in the bibliography buffer named in the warning; check and save that buffer
to finish registering it.

For example, an agent can file a draft directly:

#+begin_src emacs-lisp
(library-import-pdf
 "/path/to/draft.pdf"
 "@unpublished{lesesvre-hdr,
  author = {Lesesvre, Didier},
  title = {Arithmetic Statistics for Automorphic Forms},
  note = {Draft habilitation thesis, Université de Lille}
}")
#+end_src

To prepare an entry for human review instead, call
=(library-process-manual FILE BIBTEX)=.  It returns the displayed citation
buffer; nothing is filed until =C-c C-c=.

* Retrieving and filing papers with an agent
The optional =library-agent-shell.el= integration provides
=library-agent-shell-download-paper=.  Describe a paper by title, citation,
DOI, URL, arXiv identifier, or local PDF path.  The command starts a new
[[https://github.com/xenodium/agent-shell][agent-shell]] session in the bibliography's directory and immediately submits
instructions to find the paper, verify its metadata and PDF, and file it
through =library-import-pdf=.  The instructions use your configured library
paths and ask the agent to preserve existing metadata and manuscript copies.
The command returns the shell buffer, where you can follow its progress.

Use =library-agent-shell-file-documents= to file PDFs you have already
downloaded.  It prompts for a PDF or directory, starting in
=library-download-directory=.  For directories, only the PDFs directly
inside are considered.  In Dired it uses marked files, or the file at point;
with a prefix argument it always prompts.  This command permits metadata
lookups but tells the agent not to download PDFs or source archives.

Install agent-shell separately to use this feature; ordinary library commands
do not require it.  With a checkout on =load-path=, run
=(require 'library-agent-shell)= first.  Package managers that generate
package autoloads expose both commands automatically.  Installing only the
single =library.el= file does not include this optional integration.

By default, agent-shell offers its usual agent selection, honoring
=agent-shell-preferred-agent-config=.  Customize
=library-agent-shell-config-function= to supply a no-argument function that
returns a particular agent configuration, including any desired model or
session options.  For example:

#+begin_src emacs-lisp
(defun my-library-agent-config ()
  (require 'agent-shell-openai)
  (agent-shell-openai-make-codex-config))

(setq library-agent-shell-config-function #'my-library-agent-config)
#+end_src
